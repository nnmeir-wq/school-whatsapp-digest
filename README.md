# סוכן סיכום הודעות בוקר מקבוצות הוואטסאפ של בית הספר

סקריפט שרץ פעם ביום (07:00 שעון ישראל), קורא את כל השורות שנמצאות כרגע
בגיליון גוגל שיטס (אליו כבר כותבת אוטומציית Tasker + AutoNotification בטלפון
שלך - **חלק הזה קיים ולא נגענו בו**), מסכם אותן בעברית לפי ילד באמצעות Claude,
שולח את הסיכום במייל, ומוחק את השורות שעובדו כדי שמחר הגיליון יתחיל נקי.

**המאגר הזה ציבורי בכוונה** - הקוד עצמו גנרי ולא מכיל שום מידע אישי. כל
הפרטים הרגישים (שמות ילדים, שמות קבוצות, כתובות מייל, מפתחות API) נמצאים
רק אצלך, בקובץ `.env` מקומי (לא נכנס ל-git) או ב-GitHub Secrets מוצפנים.

## מבנה הפרויקט

```
main.py          - הזרימה הראשית (קרא -> סכם -> שלח -> מחק), כולל טיפול בשגיאות
sheets_client.py - קריאה ומחיקה של שורות בגיליון גוגל שיטס
summarizer.py     - קריאה אחת ל-Claude API שמסכמת ומסננת רעש
mailer.py         - שליחת המייל. הפונקציה send_digest() מבודדת בכוונה -
                    בעתיד, כדי לעבור לשליחה בוואטסאפ, צריך להחליף רק אותה.
config.py         - קריאת הגדרות מ-env, כולל מיפוי קבוצה -> ילד
```

---

## שלב 1: הגדרת Google Cloud + Service Account

1. היכנס ל-[Google Cloud Console](https://console.cloud.google.com/).
2. צור פרויקט חדש (או השתמש בקיים): תפריט עליון -> **New Project** -> תן שם, למשל
   `school-digest` -> **Create**.
3. ודא שהפרויקט החדש נבחר (בפינה השמאלית העליונה), ואז הפעל את ה-API:
   חפש בסרגל החיפוש **"Google Sheets API"** -> היכנס לדף שלו -> **Enable**.
4. צור Service Account:
   בתפריט הצד -> **IAM & Admin** -> **Service Accounts** -> **Create Service Account**.
   תן שם (למשל `school-digest-bot`) -> **Create and Continue** -> אפשר לדלג על
   שלבי ההרשאות (Role) -> **Done**.
5. צור מפתח JSON להתחברות:
   לחץ על ה-Service Account שיצרת -> טאב **Keys** -> **Add Key** -> **Create new key**
   -> בחר **JSON** -> **Create**. קובץ JSON יורד למחשב שלך - **זהו קובץ סודי**,
   אל תעלה אותו ל-git.
6. שים לב לכתובת המייל של ה-Service Account (נראית כמו
   `school-digest-bot@<project-id>.iam.gserviceaccount.com` - מופיעה גם בקובץ
   ה-JSON תחת `client_email`).
7. שתף את הגיליון שלך עם כתובת המייל הזו, **בהרשאת עריכה (Editor)** - זה נחוץ
   כי הסקריפט גם מוחק שורות. פתח את הגיליון -> **Share** -> הדבק את כתובת
   המייל של ה-Service Account -> בחר Editor -> Send.

## שלב 2: מפתח API של קלוד

1. היכנס ל-[platform.claude.com](https://platform.claude.com/) (חשבון Anthropic).
2. **API Keys** -> **Create Key** -> שמור את המפתח (מתחיל ב-`sk-ant-`).

## שלב 3: App Password של ג'ימייל (שליחת המייל)

1. הפעל אימות דו-שלבי (2-Step Verification) בחשבון הג'ימייל שממנו יישלח המייל,
   אם עדיין לא מופעל: [myaccount.google.com/security](https://myaccount.google.com/security).
2. באותו עמוד אבטחה -> **App passwords** (סיסמאות אפליקציה) -> צור סיסמה חדשה
   לאפליקציה בשם, למשל, `school-digest` -> גוגל תציג סיסמה בת 16 תווים - זו
   הסיסמה שנכניס בהגדרות (`SMTP_PASSWORD`), **לא** הסיסמה הרגילה של החשבון.

## שלב 4: הרצה מקומית (בדיקה)

```bash
git clone https://github.com/nnmeir-wq/school-whatsapp-digest.git
cd school-whatsapp-digest
python -m venv .venv
source .venv/bin/activate      # ב-Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env
```

ערוך את `.env` והזן:

- `ANTHROPIC_API_KEY` - המפתח משלב 2.
- `GOOGLE_SERVICE_ACCOUNT_JSON` - נתיב לקובץ ה-JSON שהורדת בשלב 1 (למשל
  `./service-account.json` - שים את הקובץ בתיקיית הפרויקט; הוא כבר מוגדר
  ב-`.gitignore` כדי שלא יעלה ל-git בטעות).
- `SPREADSHEET_ID` - ה-ID של הגיליון שלך (החלק שבין `/d/` ל-`/edit` בכתובת).
- `SMTP_USER` - כתובת הג'ימייל ששולחת את המייל.
- `SMTP_PASSWORD` - סיסמת האפליקציה בת 16 התווים משלב 3.
- `RECIPIENT_EMAILS` - כתובות המייל שיקבלו את הסיכום, מופרדות בפסיקים.
- `GROUP_TO_CHILD_JSON` - מיפוי קבוצה -> ילד, כמחרוזת JSON אחת ללא מעברי
  שורה, למשל:
  `{"כיתה ב׳ שדות": "יערי", "גן שיבולת": "תבור"}`

הרצה:

```bash
python main.py
```

בדוק בתיבת הדואר שהגיע מייל (או "אין עדכונים היום" אם הגיליון ריק), ובדוק
בגיליון שהשורות שעובדו נמחקו.

**חשוב:** מומלץ להריץ פעם ראשונה על עותק/גיבוי של הגיליון, או לוודא שיש לך
העתק של הנתונים הקיימים, כי הרצה מוצלחת מוחקת את השורות מהגיליון האמיתי.

## שלב 5: הפעלת התזמון האוטומטי (GitHub Actions)

לאחר שהרצה מקומית עבדה בהצלחה:

1. במאגר ב-GitHub -> **Settings** -> **Secrets and variables** -> **Actions**
   -> **New repository secret**, והוסף secret לכל אחד מהערכים הבאים (בדיוק
   באותם שמות):

   | Secret | ערך |
   |---|---|
   | `ANTHROPIC_API_KEY` | מפתח ה-API של קלוד |
   | `GOOGLE_SERVICE_ACCOUNT_JSON` | **תוכן קובץ ה-JSON כולו** (פתח את הקובץ, העתק-הדבק את כל התוכן) |
   | `SPREADSHEET_ID` | ה-ID של הגיליון |
   | `SMTP_USER` | כתובת הג'ימייל השולחת |
   | `SMTP_PASSWORD` | סיסמת האפליקציה בת 16 התווים |
   | `RECIPIENT_EMAILS` | כתובות הנמענים, מופרדות בפסיקים |
   | `GROUP_TO_CHILD_JSON` | מיפוי קבוצה -> ילד, כמחרוזת JSON אחת |

2. קובץ ה-workflow כבר קיים ב-`.github/workflows/daily-digest.yml` ומוגדר
   לרוץ כל יום ב-07:00 שעון ישראל (עם סטייה של שעה בערך פעמיים בשנה סביב
   מעברי שעון - זה תקין).

3. **בדיקה ידנית לפני שסומכים על התזמון**: בטאב **Actions** במאגר -> בחר
   בworkflow **Daily School Digest** -> **Run workflow** -> **Run workflow**.
   עקוב אחרי הלוג, ובדוק שהגיע מייל ושהשורות נמחקו מהגיליון.

4. מרגע שזה עובד, אין צורך לעשות שום דבר נוסף - ה-workflow ירוץ אוטומטית כל
   בוקר, גם כשהמחשב והטלפון שלך כבויים.

### חלופה: הרצה מקומית עם cron (למשל על Raspberry Pi תמידי-דלוק)

אם אתה מעדיף להריץ ממכשיר מקומי במקום GitHub Actions:

```bash
crontab -e
```

הוסף שורה (מניח שהפרויקט נמצא ב-`/home/pi/school-whatsapp-digest` והסביבה
הוירטואלית ב-`.venv`; שנה בהתאם):

```
0 7 * * * cd /home/pi/school-whatsapp-digest && .venv/bin/python main.py >> /home/pi/school-whatsapp-digest/digest.log 2>&1
```

זה ירוץ לפי שעון המערכת המקומי - ודא שהמכשיר מוגדר לאזור זמן `Asia/Jerusalem`
(`timedatectl set-timezone Asia/Jerusalem`), ואז אין צורך בהמרות UTC כלל.

## טיפול בשגיאות

בכל אחד מהשלבים (קריאת הגיליון, קריאת ה-API של קלוד, שליחת המייל, מחיקת
השורות) - אם משהו נכשל, נשלח מייל נפרד קצר בנוסח "האוטומציה נכשלה היום"
עם סיבת הכשל, כדי שתדע שמשהו לא עבד גם כשלא הגיע מייל סיכום רגיל. הלוג
המלא זמין תמיד גם בטאב Actions בגיטהאב (לחיצה על הריצה הרלוונטית).

## גמישות לעתיד: מעבר לוואטסאפ

כל לוגיקת השליחה עוברת דרך פונקציה אחת מבודדת - `send_digest()` בקובץ
`mailer.py`. כשתרצה לעבור לשליחת וואטסאפ דרך שירות MCP חיצוני, צריך להחליף
רק את הגוף של הפונקציה הזו (או ליצור מודול חדש, למשל `whatsapp_sender.py`,
ולקרוא לו במקום מ-`main.py`) - שאר הקוד (קריאה מהגיליון, סיכום, מחיקה) לא
צריך להשתנות.

## מבנה הגיליון הצפוי

| עמודה | תוכן |
|---|---|
| A | תאריך ושעה של ההודעה |
| B | שם הקבוצה, כפי שמופיע בהתראת וואטסאפ |
| C | טקסט ההודעה הגולמי (כולל בדרך כלל את שם השולח/ת בתחילתו) |

הסקריפט מזהה אוטומטית אם יש שורת כותרות בשורה הראשונה (לפי בדיקה האם התא
הראשון בשורה נראה כמו תאריך) - אין צורך להסיר אותה ידנית, אבל גם לא נורא אם
היא לא קיימת.

מיפוי קבוצה -> ילד מוגדר על ידך ב-`GROUP_TO_CHILD_JSON` (ב-`.env` מקומי או
ב-GitHub Secrets) - לא בקוד עצמו, כדי שהמאגר הציבורי לא יחשוף מידע אישי.
קבוצה שלא מופיעה במיפוי עדיין תסוכם, תחת כותרת "קבוצה לא מזוהה:
&lt;שם הקבוצה&gt;" - כדי שלעולם לא יאבד מידע בשקט.
